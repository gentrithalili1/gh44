# Learning

- When I state a rule or preference, or say "learn this", and you are very sure what I mean and where it belongs, write it to `~/gh44` yourself, commit, push, and tell me in one line.
- When you want to add or change a rule, skill, hook or lint rule yourself, when you want to add an item from the inbox, or when you are not sure: run `/gh44-learn` and ask me with the question tool, showing the exact text and where it goes. Write it only after I approve.
- After I approve, commit and push in `~/gh44`. Never commit there without one of these two.
